<section class="acad-section">
  <h2 class="acad-h2">Utvalgte satsinger i detalj</h2>

  <h3 class="acad-h3">Strategisk utviklingsarbeid</h3>
  <ul style="color:var(--body);">
    <li>Forfattet NLA Høgskolens digitaliseringsstrategi og ledet arbeidet med implementering</li>
    <li>Vært sentral i oppstarten av NLA Høgskolens satsing på fleksible nettstudier</li>
    <li>Pedagogisk rådgivning i forbindelse med campusutvikling og nybygg</li>
    <li>Ledet intern ekspertgruppe for kunstig intelligens, med ansvar for rapporten <em>Om kunstig intelligens på NLA Høgskolen</em></li>
  </ul>

  <h3 class="acad-h3">Pedagogisk innovasjon og læringsmiljø</h3>
  <ul style="color:var(--body);">
    <li>Initiert og utviklet <a href="https://sites.google.com/view/nlalab/start" target="_blank" rel="noopener">Læringslaben ved NLA</a>, som senere er utvidet med både Lekelab og Gamelab</li>
    <li>Etablert infrastruktur for selvbetjent videoproduksjon og podcast, inkludert selvkjøringsstudio og dedikerte podcastrom</li>
    <li>Bidratt til utviklingen av teknologisk tilpassede undervisningsrom, som Zoom Rooms og Active Learning Classrooms</li>
  </ul>

  <h3 class="acad-h3">Digital undervisning, rammeverk og læremidler</h3>
  <ul style="color:var(--body);">
    <li>Utviklet rammeverket <a href="/portfolio/portfolio-2/">FJORD (Flexible, Journey-Oriented, Remote Design)</a> for nettbaserte og fleksible studier</li>
    <li>Koordinert og vært faglig bidragsyter i det europeiske samarbeidsprosjektet <a href="/portfolio/portfolio-3/">DIDLE</a></li>
    <li>Utviklet læringsressursen <a href="https://programmering.snorhagen.no" target="_blank" rel="noopener">programmering.snorhagen.no</a> og <a href="/portfolio/VR%20i%20KRLE/">VR og 360°-video i KRLE</a></li>
  </ul>
